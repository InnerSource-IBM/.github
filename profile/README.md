<h1 align="center">IBM InnerSource</h1>

<p align="center"><strong>Sharing what we learn scaling InnerSource at IBM.</strong></p>

We're the IBM InnerSource team. InnerSource borrows the collaboration model of open source, but it isn't open source. IBM's InnerSource projects live inside the company on IBM GitHub Enterprise, with their own access controls, governance, Trusted Committers, and contribution requirements shaped by IBM's business needs. We help IBMers discover, reuse, and contribute to those projects across the company.

This organization is the public side of that work. When we build something useful beyond IBM's walls, like our Hacktoberfest skill, we share it here so other maintainers and InnerSource programs can reuse it.

---

## <img src="https://raw.githubusercontent.com/InnerSource-IBM/hacktoberfest-skill/main/assets/pumpkin.svg" alt="" height="28"> Hacktoberfest 2026

Every October, IBM runs **IBM Hacktoberfest**, a company-wide program that brings IBMers together to contribute to InnerSource and open source projects. This year we're also proud to sponsor the worldwide [Hacktoberfest](https://hacktoberfest.com), powered by MLH and DEV and presented by DigitalOcean, with a 2026 focus on building with open source AI and open-weight models.

We built an AI agent skill that does the tedious prep work of getting a repository ready for contributors. **It's open to everyone:** any maintainer can use it on any GitHub project for the worldwide Hacktoberfest. We also run an internal copy to support IBM Hacktoberfest, where IBMers contribute to IBM's InnerSource and open source projects.

| Repository | What it does |
|---|---|
| [**hacktoberfest-skill**](https://github.com/InnerSource-IBM/hacktoberfest-skill) | An AI agent skill that gets any GitHub repository Hacktoberfest-ready: checks and adds the `hacktoberfest` topic, triages open issues, and labels the good ones, with your approval at every step. Works with IBM Bob ([free trial](https://bob.ibm.com/trial)), Claude Code, or your agent of choice. |
